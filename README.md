# Python Practice Projects

A collection of small Python projects focused on building core programming skills through hands-on practice.

## Overview

This repository contains multiple mini-projects covering fundamental programming concepts such as:

* User input handling
* Loops and control flow
* Functions and modular design
* Error handling
* Basic algorithms and logic building

Each project is organized in its own directory inside `src/`.

## Projects

### 1. Average Number

Calculate the average of multiple user inputs.

### 2. Guessing Game

User tries to guess a number generated by the computer with hints.

### 3. PC Guesser

Computer guesses the user's number using binary search.

### 4. Rock Paper Scissors

Classic game against the computer with win/lose logic.

### 5. Run Timing

Calculate average running distance from multiple entries.

### 6. Sentence Count

Analyze a sentence (characters, words, vowels).

### 7. Summing Numbers

Different versions:

* Easy → simple sum
* Medium → list-based sum
* Professional → full statistics (count, avg, min, max)

### 8. Hex Output

Number conversion and formatting practice.
