# Summing Numbers (Medium)

A Python program that collects numbers from the user and calculates the running total using a list.

## Description

* Enter numbers one by one
* Press ENTER to stop input
* The program stores numbers in a list
* Displays the current sum after each input

## Features

* Continuous input loop
* Uses list to store numbers
* Real-time sum calculation with `sum()`
* Simple and clear structure

## Requirements

* Python +3.7

## Game Structure
```
|
|--scr/
    |--sum.py-the main game
|
|--README.md - This file

```

## How to Run

```
python sum.py
```

## How It Works

* Initializes an empty list `numbers`
* Takes user input inside a loop
* Converts input to integer and stores it
* Uses `sum(numbers)` to calculate total
* Prints updated sum after each entry
* Stops when input is empty
