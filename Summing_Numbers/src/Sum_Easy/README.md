# Summing Numbers

A simple Python program that continuously takes numbers as input and calculates their total sum.

## Description

* Enter numbers one by one
* Press ENTER to stop the program
* The program keeps adding numbers and shows the running total

## Features

* Continuous input loop
* Real-time sum calculation
* Simple and minimal logic
* Easy to understand structure

## Requirements

* Python +3.7

## Project Structure

```
Summing_Numbers/

    │

        └── README.md     # this file
```

## How to Run

```
python sum.py
```

## How It Works

* The program starts with `total = 0`
* User inputs numbers
* Each number is converted to integer and added to total
* Current total is printed after each entry
* Loop stops when input is empty
