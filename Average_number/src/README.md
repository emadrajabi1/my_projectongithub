# Average Calculator

A simple Python script to calculate the average of user-entered numbers.

## Features

* Accepts multiple numbers from user input
* Stops when ENTER is pressed
* Handles invalid input safely
* Calculates and displays the average

## Requirements

* Python +3.7

## Project Structure

```
|
|--str/
    |--average.py-the main project
|
|--README.md - This file

```

## How to Run

```
python average.py
```

## Usage

* Enter numbers one by one
* Press ENTER with no input to finish
* The program shows:

  * List of numbers
  * Count of numbers
  * Average

## Example

```
Enter a number (ENTER to stop): 10
Enter a number (ENTER to stop): 20
Enter a number (ENTER to stop): 30
Enter a number (ENTER to stop):

numbers: [10.0, 20.0, 30.0]
count: 3
--------------------------------------------------
average: 20.0
```
