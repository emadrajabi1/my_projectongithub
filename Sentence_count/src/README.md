# Sentence Count - Text Analyzer

A Python program to analyze a sentence and count characters, words, and vowels.

## Description

* Input a sentence
* The program computes:

  * Total characters
  * Total words
  * Total vowels (a, e, i, o, u)

## Features

* Counts characters, words, and vowels
* Case-insensitive vowel detection
* Simple output formatting
* Minimal logic for clarity

## Requirements

* Python +3.7

## How to Run

```bash id="k2m8zp"
python text.py
```

## How It Works

* The sentence is read as a string
* Characters are counted using length
* Words are counted by splitting the string
* Vowels are counted by iterating and matching

## Example

```id="d9q4lx"
Enter a sentence: Hello World

Characters: 11
Words: 2
Vowels: 3
```
