# Run Timing - Average Running Calculator

A simple Python program to calculate the average distance (in KM) of running sessions.

## Description

* Enter distances (in kilometers) one by one
* Press ENTER with no input to stop
* The program calculates the average distance

## Features

* Continuous input until stopped
* Supports multiple entries
* Automatic average calculation
* Handles invalid input safely

## Requirements

* Python +3.7

## Game Structure
```
|
|--str/
    |--run.py-the main game
|
|--README.md - This file

```

## How to Run

```
python run.py
```

## How It Works

* User inputs distances
* Invalid values are ignored
* Data is stored in a list
* Total and count are calculated
* Average is computed and displayed
